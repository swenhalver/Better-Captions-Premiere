# Better Captions 0.7.28 — approved spacing inspector

The production Mac ribbon uses the selected Open layout in a Scan popup beside
line height. Margin controls sit outside padding, with radius inputs in the
corners. Each group cycles between all linked, opposite sides linked and
independent, defaulting to all linked. Linked gestures update all affected sides
as one saved style change. Per-side padding, signed margins and independent
corner radii persist in the append-only BCAP v7 footer; old v1–6 documents retain
their original bytes unless geometry is edited. Install the updated native effect
along with the panel to render v7 geometry.

The font-color icon previews exact color and alpha. Word background uses the
neutral off icon when disabled, and exact RGBA over a checkerboard when enabled.
Inactive outlines use an unfilled neutral icon. Color pickers use a conventional
saturation/value field, hue strip and alpha selector beneath it.

The experimental native Mac renderer adds per-side geometry and corner paths.
Existing native Effect Controls and parameter indices are unchanged.
