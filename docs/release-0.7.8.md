# Better Captions 0.7.8

Development prerelease with completed installed Mac checks and the acceptance limits below. Includes the one-clip, automatic-track, deleted-caption recovery and safe legacy conversion changes from [0.7.3](release-0.7.3.md).

The completed 0.7.6 native core checks cover core source retained in 0.7.8. Adobe's same-version 0.7.6 reinstall had left an earlier UXP helper installed; the unique 0.7.7 installation loaded the new project-bin lookup but returned an unqualified native `Invalid parameter.` error. Version 0.7.8 supplies the documented generic `ProjectItem` wrapper to the insert API and adds bounded native phase/context diagnostics. Its byte-verified native automatic-track test passed. That success does not prove the exact cause of the earlier generic error.

Fixes an installed Premiere ExtendScript syntax error in file-path validation. Absolute local path validation and traversal/network path rejection remain enforced. Motion and geometry timing now use explicit branches in place of nested conditional expressions that failed in the installed host when a caption had no native split fragments. Motion read failures retain bounded phase, frame and native line details.

Fixes single-clip retiming readback without weakening native Razor and shared-media checks. Hidden legacy captions are rejected before conversion so disabled clips or muted tracks cannot become visible unexpectedly.

The render service checks its native evaluator, loads only the installed extension-owned host when required, publishes the verified namespace on the global script object, and verifies global identity and every required method from a separate evaluation before timeline work. This prevents a caller-local file load from reporting readiness while later calls still use an older global bridge. Failed startup readiness can be retried by a later request after a one-second cooldown. Timeline mutations are never retried after an ambiguous response.

Automatic-track setup resolves its imported seed through a bounded project-root/bin traversal, with exact path, uniqueness and non-sequence checks before creating Actions. This replaces an opaque path search that reported the seed missing or ambiguous in the earlier installed host; the precise reason for that API result is not established. In the installed 0.7.8 Mac test, Apply converted two unlinked sentence captions into one native bundle on a newly created V2 above the existing V1 source. The final timeline read confirmed the new clip/item identities and 110-frame range. All 23 checked UXP/CEP files matched the staged payload before Premiere launched.

Confirmed on Mac after a clean Premiere restart: a full Apply completed successfully for an existing caption bundle, retaining its native clip and project-item identities and its render Motion profile. Grouping, native keyframe edits/history, unsplit retiming and Razor-fragment source-clock preservation also have recorded native passes. A final 0.7.8 Fresh Speech Apply and save retained its static bundle identity, 104-frame range, four groups and exact raw Motion curves. The final saved-project audit confirmed three production sequence graphs and protected Motion after documented serialization normalization, with existing source media, 16 foreign dirty files and preset bytes preserved. This is not a claim that every feature has native acceptance.

Physical dragging remains unaccepted: automation displayed blue transform handles but did not confirm a Position or size change. Opaque/custom native Position easing remains protected when moving/removing keys cannot preserve exact Undo; use Premiere Effect Controls for those operations. Compatible static legacy conversion has not had a successful native acceptance test. Windows native acceptance remains blocked by Adobe installation.

Final source verification: `npm test` completed with 527 tests, 525 passed, no failures and two Windows-only tests skipped on Mac. `npm run check` reported zero errors and zero warnings. See the [Mac verification record](mac-verification-0.7.8.md) for completed native checks and remaining limits. Source and CI checks do not substitute for installed-host validation.
