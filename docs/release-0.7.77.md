# S-Captions 0.7.77

- Scrolling text: blank rows now appear only for pauses at least as long as an average line, and each blank row stands for one average line of silence (previously 0.6 s). (Native caption plug-in, reinstalled with this version.)
- Includes 0.7.76: Cmd in the line editor commits pending typing as its own Premiere undo step first, then writes the text, so Cmd+Z right after typing undoes exactly that burst and Shift+Cmd+Z brings it back.
