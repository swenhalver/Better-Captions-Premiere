# Better Captions 0.7.48

Word-background visibility is paint-only: authored horizontal padding and margins reserve identical glyph origins, widths and Smart groups with the background enabled or disabled. Native CoreText and canvas paths share this rule. Editing padding still changes its authored geometry.

Number controls support immediate single-click typing, dragging, and double-click reset. In Past/Current/Next style scopes, reset copies the current All words value. All words resets use known factory values. Native dimension resets retain sequence-derived 90% defaults, and resetting one Position axis preserves the other. Characters per caption resets to 56.

Includes the always-visible, live 15–150 character grouping control and independent scrolling box boundaries from 0.7.47.

Validation and installed-host results are recorded in mac-verification-0.7.48.md.
