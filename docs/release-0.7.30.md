# Better Captions 0.7.30 — direct shadow and layout controls

Adds the supplied Type Shadow SVG as a toolbar button with a neutral foreground
stroke and its authored gray shadow. Its popup provides the existing shadow
toggle, blur, X/Y offsets, color and alpha controls. Layout controls stay visible below the text toolbar, including their native
keyframe behavior.
Word spacing moves into the Scan spacing popup; rendered-movie letter spacing
remains available there as well. The Spacing, Outline, Shadow and Layout tabs
are removed. Popups are mutually exclusive and dismiss on Escape or outside click.
This release changes panel UI only; native renderer and saved caption values
are unchanged.
