# S-Captions 0.7.60

The native Smart line fit effect parameter is gone. The renderer only ever groups by Characters per caption. The panel's Smart line fit button measures the layer's current Width, global font size and word-state scales, then sets Characters per caption to the count that fits one line. Press it again after changing the width or font to recalculate; nothing recalculates on its own.

This build includes a rebuilt native effect. Reinstall both the panel and the native plug-in, then restart Premiere.
