# S-Captions 0.7.58

Title Case keeps your own capitalization. A word that already contains a capital (NASA, iPhone, JunkYourVehicle.Net) displays exactly as typed. Lowercase words get a capital at the start of each part, so junkyourvehicle.net shows as Junkyourvehicle.Net. The panel preview, smart line fit and the native Premiere effect now use the same rule. The Ollama casing pass from 0.7.57 is removed.
