# Temporary layout guide

The cyan layout guide no longer depends on selecting an effect header. After a confirmed Position, Width or Height edit, the bridge sets the native effect's hidden, non-keyframed `Layout editing guide` parameter to an absolute expiration timestamp. Rendering composites a cyan rectangle around the same scaled layout box used by captions.

The normal lease lasts 1.5 seconds. The renderer rejects expired timestamps and leases further than two seconds into the future, so opening an old saved project cannot enable a permanent guide. An independent CEP worker clears the actual parameter to zero after 800 ms without another geometry update. Setting zero also invalidates Premiere's cached guide frame. This worker remains independent of the visible UXP panel and reclaims pending host leases after service reload. Cleanup resolves the captured project/sequence/clip identity again, never changes user animation, and only clears the exact lease it previously created. Editing other caption controls does not turn the guide on.

The implementation changes the rendered pixels while the short lease is active. This AE effect render callback does not provide a verified monitor-versus-export context discriminator. Starting an export during a live edit can therefore include the guide; the mechanism must not be described as unconditionally export-safe. Normal settled output uses lease zero. If the CEP worker itself is terminated before clearing the value, new native renders reject the expired lease, but an already cached frame can persist until Premiere invalidates it. The worker retries cleanup while running.

Coverage includes native ASan/UBSan tests for lease expiry, long/invalid values, scaled coordinates, offscreen clipping, premultiplied ARGB output and padded row strides; bridge tests for exact lease ownership, renewed edits, clip reordering, document/control revision preservation and project guards; and worker tests proving cleanup after idle without another UXP request and retry after a busy-host error. Live Program Monitor testing is required in addition to these tests.
