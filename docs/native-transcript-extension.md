# Range-aware native transcription

`transcribeSequenceRange(beginSeconds, endSeconds, sequenceId)` returns a native transcript JSON string for the requested sequence interval. Its `segments` retain sequence-relative word times; `range` records the requested bounds. This operation does not write the Better Captions document or change any clip, caption text, style, grouping, or timing. The caller must merge the returned tail into its existing document using a separately guarded extension operation.

An existing static sequence transcript can end before newly appended audio. Range transcription therefore bypasses that shortcut and inspects the current enabled source-audio clips intersecting the requested interval. Existing source transcripts, including valid no-speech transcripts, are reused without retranscription. Only a missing or malformed source transcript invokes Premiere's built-in `Transcript.transcribeClipProjectItem`. That SDK call transcribes the source project item; the plugin then returns only words mapped into the requested timeline interval. It does not force a whole-sequence retranscription or replace source transcript edits that already exist.

Repeated media is cached within the operation and mapped for each edit using its actual source in/out and timeline duration. Muted tracks, disabled clips and clips outside the interval are skipped. Word edges crossing a range boundary are clipped to that boundary, and punctuation is retained with its included word. Nested/reversed audio inside the interval is refused. If no spoken words are returned, the operation reports that outcome explicitly rather than extending with fabricated or empty captions.

The public UXP API validates finite bounds (0 through ten days), checks the current sequence duration and active project/sequence, and retains the one-hour native transcription deadline. The source-audio plan is compared after transcription; an edit/relink during the operation refuses stale mapped results. Active project/sequence or sequence-duration changes also refuse the result. No private CEP service request is needed for this direct Premiere SDK call.

Coverage in `tests/native-transcript.test.mjs` and `tests/uxp-api.test.mjs` includes the stale static-transcript regression, clipped/retimed words, punctuation, reused sources, existing native edits and no-speech results, missing-source transcription, outside/muted/disabled exclusions, changed context, bounds and timeout behavior. These fixtures verify implementation behavior; live Premiere acceptance is a separate check.
