# 0.7.79 — Readable blank-line hover help

Completes 0.7.78's Blank line length setting with a wrapped in-panel tooltip. Hover the label or numeric field (or focus the field) to read the entire supplied explanation and example. It uses the panel's existing type, surface and spacing tokens and opens above the control so a docked panel does not clip its bottom. The matching title help remains on both targets. Native cadence, reset, keyframing and Premiere Undo/Redo are unchanged from 0.7.78.
