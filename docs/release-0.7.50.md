# Better Captions 0.7.50

The native caption layout/positioning box no longer clips text, word backgrounds, outlines or shadows. Content can extend beyond the layout and scrolling-history rectangles at its authored size.

Directional scrolling crop/fade affects only its selected edge. All four sides mode retains its explicit per-edge crop/fade settings. The actual sequence image remains the outer render limit.

This native-effect correction does not change caption words, grouping, positions, dimensions or saved styles. The legacy generated-movie export path is separate and unchanged.
