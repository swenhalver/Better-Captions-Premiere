# 0.7.80 — Pause Line Length in Caption grouping

Moves the native pause control from Styling to Transcript → Caption grouping, alongside Characters per line and Smart line fit. Its name is now **Pause Line Length** in both the panel and Effect Controls → Scrolling text. The native disk ID stays 69, preserving saved values. The field keeps 0–30 seconds in 0.1-second steps, Auto at 0, native reset, keyframe navigation and Premiere Undo/Redo. Wrapped in-panel hover/focus help explicitly explains seconds and the pause example. It is hidden when there is no native layer or the installed effect lacks the parameter.

Scrolling captions now form one continuous stream across caption splits, retaining previous lines and revealing upcoming lines according to Current line position. Pauses across split boundaries follow the same Pause Line Length/Auto rule. Paged mode also continues across storage boundaries. Every whole pause interval creates one blank line without a Visible lines cap. Blank pause lines are ordinary line slots with normal height and transitions; upcoming text remains visible past a pause line.

The panel counts and edits rendered lines. Explicit split/merge choices use per-word break/join markers in BCAP document version 8. Existing documents migrate their container edges into explicit breaks without changing words, timings, style or manual splits. Merge works across storage boundaries and timing uses adjacent speech as its limit. Split, merge and typing retain Premiere edit-token Undo/Redo. **Characters per line** keeps native disk ID 4 and its saved value.
