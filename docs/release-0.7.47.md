# Better Captions 0.7.47

- Caption grouping is always visible, without the two help paragraphs or a Regroup button.
- Characters per caption supports click-to-type and drag adjustment from 15 to 150; valid edits regroup in real time. Linked caption identities remain unchanged.
- Text box boundaries expose independent Top, Bottom, Left and Right crop/fade controls. Select All four sides to use them; existing Directional edge settings remain available. These boundaries affect scrolling text.
- Style popups follow their parent buttons during scrolling and resizing.
- Regrouping determines line breaks; rendering never wraps or shrinks a group. Silent gaps longer than 0.6 seconds reserve one timed blank row.
- Padding changes line height, while toggling a background at the same padding leaves text placement unchanged. Asymmetric padding reserves enough room for the background paint.
