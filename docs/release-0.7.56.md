# S-Captions 0.7.56

Title Case now respects intentional capitals. A word that already contains a capital letter keeps its casing, so acronyms (NASA), brands and domains (JunkYourVehicle.Net, iPhone) display as typed instead of becoming Nasa or Junkyourvehicle.net. Lowercase words still get their first letter capitalized. The panel preview, smart line fit and the native Premiere effect all use the same rule.
