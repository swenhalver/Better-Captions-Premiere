# Portable caption document and layout core

This C++17 library has no Adobe SDK dependency. It produces **draw commands**, not pixels. A native effect adapter must shape/measure fonts, draw text/bubbles/outlines/shadows, clip to the text area, and invalidate frames when its host parameters/document change. Actual Premiere rendering and native parameter behavior require separate host verification.

`Document` schema 1 stores stable caption-container IDs, manual-split markers, source words/timing, and independent upcoming/current/spoken styles. `regroup` derives phrases afresh from character count, sentence endings and pauses; it never replaces containers or modifies transcript text. Empty containers are valid. Words must be sorted by start time in each container. Timeline seconds are local to the caption container/effect; a host adapter must map sequence/clip time explicitly for trims and splits.

`layoutFrame` selects half-open `[start,end)` phrases and word activity ranges. Pauses inside a phrase retain the phrase and show earlier words as spoken. Text area coordinates are top-left pixels. Punctuation tokens attach to the preceding word without an extra space, including at regroup boundaries. Width wraps words without scaling the font; height reports overflow without altering layout. A word wider than the box also reports overflow. The caller must clip drawing, and can surface overflow in its panel. Independent overlapping containers can produce multiple draw-command sets; the host is responsible for compositing them.

The callback receives the effective per-state font style and display text. Return real shaped advance width, ascent and descent at `fontSize * sizeScale`. `DrawWord.x` and `width` describe its outer bubble bounds when a bubble is enabled; text origin is `x + padding` and baseline is the returned `baseline`. Bubble top is `baseline - ascent - padding`. Bubble bounds do not include outline/shadow extents. Titles transform ASCII letters only and preserve UTF-8 bytes; complete Unicode locale-aware title casing requires a host text library. Source words remain unchanged.

The binary codec uses fixed little-endian uint32 and IEEE-754 binary64 values; strings are byte-length-prefixed. It rejects unknown schema versions, non-finite values, malformed booleans, duplicate container IDs, invalid timings/styles, malformed UTF-8, unsupported controls (U+0000–001F, U+007F–009F, U+2028/U+2029), trailing bytes, excessive counts and sizes, and incomplete buffers. The maximum document is 16 MiB, with 100,000 total words, 10,000 containers, 4,096-byte word strings and 256-byte IDs/font names. It is a local data format, not an executable command transport. The panel must explicitly migrate legacy caption data rather than automatically replacing legacy timeline clips.

Run `native/tests/run-core-tests.sh` for strict-warning AddressSanitizer/UndefinedBehaviorSanitizer checks. The CMake test executable also accepts `--roundtrip input.bcap output.bcap` for panel/native binary interchange verification.
